會計帳務管理系統

為中小企業與會計事務所設計的基本帳務系統：會計科目、日記帳、分類帳、試算表與財務報表一次到位，並可用 AI 語音或拍攝發票快速產生分錄草稿，經人工覆核後過帳。

線上試用示範站 在 Codespaces 一鍵執行 查看 GitHub 原始碼

示範帳號：demo　密碼：demo1234
示範站資料每天自動重置為範例資料，AI 辨識功能不開放；要試用 AI，請使用 Codespaces 或自行安裝。

主要功能

依《系統規格書》開發，涵蓋日常記帳到月底報表的完整流程。

會計科目管理

資產、負債、權益、收入、費用五大類科目，依正常餘額方向顯示科目餘額。

日記帳

一借一貸分錄、憑證號自動編碼，過帳時以資料庫交易同步更新科目餘額。

分類帳

依科目逐筆列出交易與累計餘額，方便追查每一筆金額的來源。

試算表

自動彙總借方與貸方合計並驗證是否平衡。

財務報表

資產負債表（含本期損益）、損益表（可選期間）與科目餘額表。

AI

語音／拍照記帳

透過 OpenAI 辨識口述內容或發票照片，依既有科目產生分錄草稿，人工確認後才過帳。

三種使用方式

不需安裝就能先看看，想完整試用也只要按一下。

1. 線上示範站

直接在瀏覽器操作，內含九月份範例交易。以 demo / demo1234 登入。

2. GitHub Codespaces

登入 GitHub 後按「在 Codespaces 一鍵執行」，約 2～3 分鐘自動建好 PHP + MariaDB 與範例資料，完成後開啟 8080 連接埠。管理員 admin / admin123，可在「AI 設定」貼上自己的 OpenAI 金鑰。

3. 自行安裝（XAMPP）

下載原始碼放到 htdocs，以 utf8mb4 匯入 database/init.sql，開啟 /public/ 即可。詳見 GitHub 上的安裝說明。

技術規格

簡單、好部署，共享主機也能執行。

後端PHP 8（MVC 架構、PDO 參數化查詢）
資料庫MySQL / MariaDB（utf8mb4），支援資料表前綴，可與其他系統共用資料庫
前端HTML、CSS、原生 JavaScript，支援手機操作
AI 服務OpenAI 語音轉文字與影像辨識、JSON Schema 結構化輸出
安全性BCrypt 密碼、CSRF 保護、輸出編碼防 XSS、機密目錄禁止存取、審計日誌

AI 記帳如何運作

AI 只負責產生草稿，最終過帳一定由人確認。

  1. 作業人員在手機或電腦上錄音口述交易，或拍攝發票、收據。
  2. 系統把內容與科目清單交給 OpenAI，取得日期、借貸科目、金額與摘要。
  3. 伺服器再次驗證科目、金額與日期，無法確認的欄位會清空並提醒。
  4. 作業人員核對並修改草稿，按「確認過帳」後才寫入帳務。
